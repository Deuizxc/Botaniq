# BotaniQ

A garden tracking application for CUAI, Quezon City University, built with a modern web frontend, a Node.js backend (`backend.js`), and a persistent **Supabase PostgreSQL** database. Configured for serverless deployment on **Vercel**.

## Tech Stack
- **Frontend**: Plain HTML5, CSS3, and modern JavaScript (dynamic shell rendering and routing).
- **Backend**: Node.js (ES Modules) using standard `http` and the `pg` PostgreSQL client library.
- **Database**: Supabase PostgreSQL (relational tables, views, constraints, and indexes).
- **Hosting**: Vercel Serverless Functions (`api/index.js`) with static asset rewrites (`vercel.json`).
